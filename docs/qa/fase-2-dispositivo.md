# Fase 2 · Prueba en el teléfono

> Para George. Se hace en Chrome Android con la app publicada en Vercel (HTTPS). Marca cada casilla y anota lo que veas. La fase se cierra con estos checks y 7 días de uso real (CLAUDE.md, tech §0).

## Antes de empezar
- [ ] Abre la URL de Vercel en Chrome Android.
- [ ] Menú ⋮ → **Instalar app**. Aparece el ícono de Bloom en el escritorio con el símbolo del logo.
- [ ] Abre Bloom desde el ícono: se ve a pantalla completa, sin barra de Chrome, con la barra del sistema oscura.

## Brew Mode
- [ ] **Pantalla encendida:** prepara un V60 completo sin tocar el teléfono entre vertidos. La pantalla no se apaga en ningún momento (al menos 5 min).
- [ ] **Vibración** en cada evento: "Listo" (corta), 3 s antes de cambiar de paso (corta), cambio de paso (doble), pausa (corta), "Terminar brew" (doble larga).
- [ ] **Sin vibración:** en el Home, ícono de Setup → apaga "Vibración" → el aviso en pantalla basta para seguir el brew.
- [ ] **Tocar la pantalla no pausa:** toca el número, el título y el texto durante un vertido; el tiempo sigue.
- [ ] **Botón atrás de Android:** durante un brew aparece "¿Salir del brew?"; "Seguir preparando" vuelve al paso.
- [ ] **Bloquear y desbloquear** el teléfono a mitad del brew: el tiempo sigue correcto al volver.
- [ ] **Cambiar de app y volver** (por ejemplo, abrir WhatsApp 20 s): el tiempo sigue correcto.
- [ ] **Retomar tras cerrar la app:** a mitad de un vertido, ciérrala desde recientes. Ábrela otra vez: el Home ofrece "Retomar brew en m:ss" y vuelve al paso correcto.
- [ ] **Último paso:** la decantación no termina sola; "Terminar brew" abre "Tu café está listo" con el tiempo real.
- [ ] **Modo avión:** con la app instalada y abierta al menos una vez, activa modo avión, ciérrala y ábrela. El Home abre y puedes preparar un café completo.
- [ ] **Legibilidad a 50–70 cm** con el teléfono apoyado junto al dripper: la meta de gramos, el tiempo restante y el nombre del paso se leen sin acercarte.
- [ ] **Manos mojadas:** los botones "Listo", pausa y "Terminar brew" responden al primer toque.
- [ ] **TalkBack:** con TalkBack activo, cada cambio de paso se anuncia ("Primer vertido. Vierte hasta 140 gramos.").

## Home
- [ ] Antes del primer café: "Prepara tu primer café".
- [ ] Después del primer café: "Tu café habitual" muestra la receta que usaste, y "Este mes" + el tile del método suben.
